# Project overview

This is a static about-me website built with plain HTML, CSS, and JavaScript.

## Run

Start the `Start application` workflow. It runs:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the web preview to view the site.

## Customize

- Replace bracketed sample content, project copy, the email address, and location in `index.html`.
- Adjust the visual system and responsive layout in `styles.css`.
- Mobile navigation and scroll-reveal behavior are in `script.js`.
