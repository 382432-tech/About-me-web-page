# About Me Web Page

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Run on Replit

Use the **Start application** workflow. It serves the site on port 5000.

## Personalize

Edit `index.html` to replace the bracketed sample details, project descriptions, email address, and location with your own information. Visual styles live in `styles.css`, and the mobile menu and scroll animations live in `script.js`.
